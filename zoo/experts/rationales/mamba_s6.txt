**Problem Addressed:** While S4 and its variants achieved linear complexity and strong performance on continuous-signal tasks, they struggled on discrete modalities like language due to their time-invariant (LTI) property—the dynamics remain constant regardless of input content. This limitation prevents the model from selectively focusing on or ignoring specific tokens based on their relevance. Transformers excel at content-based reasoning through their attention mechanism, but at quadratic cost. The challenge was to design a state space model that could perform content-based selection (like attention) while maintaining linear complexity and efficient hardware implementation.

**Key Innovation - Selective State Space Model (S6):** Mamba makes the SSM parameters functions of the input, introducing selectivity: Δ_t = Parameter(x_t), B_t = s_B(x_t), C_t = s_C(x_t). The core token mixer implements: h_t = Ā_t h_{t-1} + B̄_t x_t, y_t = C_t h_t, where Ā_t = exp(Δ_t A) and B̄_t = (Δ_t A)^(-1)(exp(Δ_t A) - I) · Δ_t B_t are the discretized parameters. The selectivity mechanism allows the model to decide which information to retain or forget based on input content. The step size Δ_t acts as a learned gating mechanism—larger Δ_t means faster dynamics (less memory), smaller Δ_t means slower dynamics (more memory). This selective mechanism breaks the LTI property, preventing the use of convolution for training, but Mamba develops a hardware-efficient parallel scan algorithm that leverages GPU memory hierarchy (SRAM vs HBM) with kernel fusion.

**Implementation Details:**
- Selective parameters: Δ_t, B_t, C_t all depend on input x_t
- Step size as gate: Δ_t = softplus(Parameter(x_t)) controls information flow
- Discretization: Uses zero-order hold (ZOH) for converting continuous to discrete
- Hardware-efficient scan: Parallel scan algorithm with smart memory management
- Kernel fusion: Combines discretization, recurrence, and output in single kernel
- State size: Typically N=16 dimensions, much smaller than attention's O(L) KV cache
- Simplified architecture: No attention or MLP blocks, just selective SSM + projections
- 5× faster inference than Transformers, linear scaling with sequence length

**SNN Compatibility & Expected Impact:** Mamba's selective SSM with input-dependent dynamics maps naturally to adaptive spiking neural networks. The selective step size Δ_t = softplus(Parameter(x_t)) can be implemented using spiking neurons whose membrane time constants are modulated by input spike rates—higher input activity leads to faster dynamics (larger Δ_t), enabling rapid adaptation. Converting all linear projections (input projections for Δ, B, C, and output projection) to SpikingLinear layers introduces event-driven sparsity. The selective B_t and C_t parameters can be realized through spike-based gain modulation, where input spikes modulate the effective connectivity of state neurons. The discretization with ZOH naturally aligns with the discrete-time nature of spiking neurons. The compact state size (N=16) is ideal for neuromorphic hardware with limited on-chip memory. The parallel scan algorithm can be adapted for neuromorphic implementations through hierarchical spike routing. The resulting Spiking-Mamba combines the content-based selectivity crucial for language modeling with the energy efficiency of event-driven computation. The selective mechanism, when implemented through adaptive neuron dynamics and spike-based modulation, provides a biologically plausible way to achieve context-dependent processing. This makes Spiking-Mamba particularly suitable for neuromorphic implementations of language models where the ability to selectively process information based on content is essential, while maintaining the linear complexity and compact memory footprint that make deployment on power-constrained neuromorphic hardware feasible. The selective SSM represents a key breakthrough in bridging the gap between efficient recurrent models and the content-based reasoning capabilities of attention.
