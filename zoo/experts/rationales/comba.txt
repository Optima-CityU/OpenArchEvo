**Problem Addressed:** Bilinear RNNs, which use multiplicative interactions between inputs and hidden states, offer rich dynamics but can suffer from instability and difficulty in training. Linear RNNs are stable but less expressive, while bilinear RNNs are expressive but harder to control. The challenge is to design a bilinear RNN architecture that maintains expressiveness while ensuring stable training and inference through principled control mechanisms.

**Key Innovation - Closed-Loop Control for Bilinear Dynamics:** Comba introduces closed-loop control theory principles to stabilize bilinear RNN dynamics. The core token mixer implements: `S_t = A_t S_{t-1} + B_t x_t` where `A_t = f_A(x_t, S_{t-1})` is a bilinear state transition that depends on both input and current state (closed-loop), and `B_t = f_B(x_t)` is the input transformation. The key insight is using control-theoretic constraints to ensure stability: the eigenvalues of A_t are constrained to lie within the unit circle through careful parameterization. This is achieved by parameterizing A_t using stable matrix factorizations (e.g., products of matrices with bounded eigenvalues). The closed-loop nature (A_t depends on S_{t-1}) enables richer dynamics than open-loop control while maintaining stability guarantees.

**Implementation Details:**
- Bilinear state transition: `A_t = f_A(x_t, S_{t-1})` depends on both input and state
- Stability constraints: eigenvalues of A_t kept within unit circle through parameterization
- Closed-loop control: feedback from current state influences next transition
- Input-dependent dynamics: `B_t = f_B(x_t)` adapts input processing
- Can use various stable parameterizations: diagonal, low-rank, structured matrices
- Parallel training possible through careful algorithm design
- More expressive than linear RNNs while maintaining stability of controlled systems

**SNN Compatibility & Expected Impact:** Comba's closed-loop bilinear dynamics map naturally to recurrent spiking neural networks with multiplicative interactions. The bilinear state transition `A_t = f_A(x_t, S_{t-1})` can be implemented using populations of spiking neurons where synaptic efficacy is modulated by both input spikes and recurrent activity—a form of gain modulation common in biological neural systems. Converting all linear projections (f_A, f_B, output projections) to SpikingLinear layers introduces event-driven sparsity. The closed-loop control (dependence on S_{t-1}) naturally emerges from recurrent connectivity in spiking networks. The stability constraints can be enforced through careful design of synaptic weight matrices and inhibitory feedback loops that prevent runaway excitation. The multiplicative interactions can be realized through dendritic computations in spiking neurons where different input streams interact nonlinearly. The resulting Spiking-Comba combines the expressiveness of bilinear dynamics with the energy efficiency of sparse, event-driven computation and the stability of controlled systems. The closed-loop control, when implemented through recurrent inhibition and gain modulation in spiking networks, provides a biologically plausible mechanism for stable yet expressive sequence processing. This makes Spiking-Comba particularly suitable for neuromorphic implementations of complex dynamical systems where both rich temporal dynamics and stable operation are required, with the bilinear interactions enabling the model to capture complex input-state relationships while the control-theoretic constraints ensure reliable operation on neuromorphic hardware.
