**Problem Addressed:** While RWKV6 introduced data-dependent decay and matrix-valued states, it still faced limitations in state-tracking capabilities and was constrained by the TC^0 complexity class (like Transformers), limiting its theoretical expressiveness for certain computational tasks. The model needed more flexible state evolution mechanisms to handle complex reasoning tasks and recognize all regular languages—capabilities that go beyond standard Transformers. The challenge was to design a more expressive state update rule that maintains computational efficiency while exceeding the representational limitations of both Transformers and previous RWKV versions.

**Key Innovation - Generalized Delta Rule with Vector-Valued Gating:** RWKV7 introduces a newly generalized formulation of the delta rule with vector-valued gating and in-context learning rates, along with a relaxed value replacement rule. The core token mixer implements: `S_t = S_{t-1}(I - κ̂_t^T(a_t ⊙ κ̂_t)) + β_t v_t κ̂_t^T` where the transition matrix `G_t = diag(w_t) - κ̂_t^T(a_t ⊙ κ̂_t)diag(w_t)` approximates a scaled Householder matrix. Here, `w_t` acts as a vector-valued learning rate, `a_t` provides element-wise gating, and `κ̂_t` is a normalized key vector. This formulation allows the network to perform selective state updates in multiple subspaces simultaneously, with different learning rates and gating values per dimension. Unlike RWKV6's scalar decay, this vector-valued approach enables much richer dynamics and state evolution patterns.

**Implementation Details:**
- Vector-valued gating: `a_t = σ(x_t W_a)` provides per-dimension control over state updates
- Vector-valued learning rate: `w_t = exp(-exp(x_t W_w))` enables adaptive learning per dimension
- Normalized keys: `κ̂_t = k_t / ||k_t||` for stable state transitions
- Relaxed value replacement: `β_t v_t κ̂_t^T` where `β_t = σ(x_t W_β)` controls new information injection
- Transition matrix eigenvalues remain in stable range [-1, 1] through Householder-like structure
- Maintains parallelizable training through chunk-wise formulation
- Achieves state-tracking capabilities beyond TC^0, can recognize all regular languages

**SNN Compatibility & Expected Impact:** RWKV7's vector-valued gating and learning rates map naturally to heterogeneous populations of spiking neurons with diverse dynamics. The per-dimension gating `a_t` can be implemented using separate populations of inhibitory neurons that modulate information flow in different subspaces. The vector-valued learning rate `w_t` corresponds to neurons with different membrane time constants and refractory periods, enabling multi-timescale processing. Converting all projections (W_k, W_v, W_a, W_w, W_β, W_o) to SpikingLinear layers introduces event-driven sparsity. The Householder-like state transition can be efficiently implemented in neuromorphic hardware through structured spike routing patterns. The normalized keys `κ̂_t` can be realized using divisive normalization circuits common in biological neural systems. The resulting Spiking-RWKV7 combines the enhanced expressiveness of generalized delta rule dynamics with the energy efficiency of sparse, event-driven computation. The vector-valued gating enables the model to selectively process different feature dimensions based on input-driven spike patterns, making it particularly suitable for complex reasoning tasks on neuromorphic hardware where the rich state evolution dynamics can be efficiently realized through heterogeneous neuron populations with diverse temporal properties.
