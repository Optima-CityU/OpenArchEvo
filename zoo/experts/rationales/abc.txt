**Problem Addressed:** Standard attention mechanisms require O(N²) time and O(N) space complexity, making them impractical for long sequences. While various efficient attention methods exist, they lack a unified framework for understanding their design principles and trade-offs. The challenge is to develop a general approach that bounds memory size while maintaining attention's expressiveness, and to provide theoretical understanding of how different efficient attention variants relate to each other.

**Key Innovation - Slot-Based Memory with Control Vectors:** ABC introduces a unified framework where attention operates on a fixed-size memory with n slots (n << N). The core insight is reformulating attention using control vectors that select which information to store in bounded memory. The token mixer implements: `K̃ = Σ φ_i ⊗ k_i, Ṽ = Σ φ_i ⊗ v_i` where `φ_i ∈ R^n` are control vectors that determine how each token contributes to the n memory slots. The output is computed by attending to this bounded memory: `o_t = Ṽ^T softmax(K̃ q_t)`. This formulation has an equivalent recurrent form: `K̃_t = K̃_{t-1} + φ_t ⊗ k_t, Ṽ_t = Ṽ_{t-1} + φ_t ⊗ v_t` which enables O(1) inference with O(n) memory. Different choices of control vectors φ_i yield different efficient attention variants.

**Implementation Details:**
- Fixed-size memory with n slots (typically 32-256), independent of sequence length N
- Control vectors φ_i determine information allocation across slots
- Recurrent update: memory accumulates weighted contributions from each token
- Reading from memory: O(n) complexity via `softmax(K̃ q_t)`
- Overall complexity: O(Nn) - linear in sequence length
- Unifies multiple efficient attention methods: linear attention (φ_i = feature_map(k_i)), random feature attention, etc.
- Can use learned or fixed control vectors depending on variant

**SNN Compatibility & Expected Impact:** ABC's slot-based memory architecture with control vectors maps naturally to neuromorphic implementations. The fixed number of slots corresponds to dedicated populations of spiking neurons serving as working memory units. Converting all linear projections (q_proj, k_proj, v_proj, control vector computations, output projections) to SpikingLinear layers introduces event-driven sparsity. The control vectors φ_i can be implemented using spike-based gating mechanisms where input spikes modulate the routing of information to different memory slots. The recurrent memory update `K̃_t = K̃_{t-1} + φ_t ⊗ k_t` can be efficiently realized in neuromorphic hardware through accumulator circuits that integrate spike trains. The softmax operation for reading from memory can be approximated using lateral inhibition mechanisms common in biological neural networks. The bounded memory size (n slots) provides a natural constraint for neuromorphic hardware with limited on-chip memory. The resulting Spiking-ABC combines the memory efficiency of slot-based attention with the computational efficiency of sparse, event-driven processing. The control vector mechanism, when implemented through spike-based routing, enables dynamic allocation of memory resources based on input-driven spike patterns. This makes Spiking-ABC particularly suitable for neuromorphic implementations of efficient attention where both memory footprint and energy consumption must be minimized, while maintaining the flexibility to adapt memory allocation to different sequence processing tasks.
