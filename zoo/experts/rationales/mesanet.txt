**Problem Addressed:** Traditional sequence models learn fixed parameters during training and apply them unchanged during inference. However, optimal processing of a sequence may require adapting the model's parameters based on the specific input sequence being processed. The challenge is to enable test-time adaptation in a computationally efficient manner that improves sequence modeling without requiring expensive optimization at inference time.

**Key Innovation - Local Test-Time Training:** MesaNet introduces a mechanism for locally optimal test-time training where the model adapts its parameters based on local sequence context during inference. The core idea is to perform gradient-based updates on a subset of parameters using a local objective computed from recent tokens. The token mixer implements: `θ_t = θ_{t-1} - η ∇_θ L_local(x_{t-w:t}; θ_{t-1})` where θ_t are adapted parameters, L_local is a local loss computed on a sliding window of recent tokens, and η is a learning rate. The model then processes the current token using adapted parameters: `o_t = f(x_t; θ_t)`. This creates a form of meta-learning where the model learns how to adapt itself during inference.

**Implementation Details:**
- Test-time parameter adaptation: updates subset of parameters based on local context
- Local objective: computed on sliding window of recent w tokens (typically w=32-128)
- Gradient-based updates: uses efficient approximations for fast adaptation
- Selective adaptation: only adapts subset of parameters (e.g., attention weights)
- Maintains base parameters: adapted parameters reset or decay back to base
- Can be combined with various base architectures (Transformer, linear attention, etc.)
- Improves performance on distribution shift and long-context tasks

**SNN Compatibility & Expected Impact:** MesaNet's test-time adaptation mechanism can be mapped to spike-timing-dependent plasticity (STDP) and other local learning rules in spiking neural networks. The local objective L_local can be computed using local spike statistics within a temporal window. Converting all linear projections to SpikingLinear layers introduces event-driven sparsity. The gradient-based parameter updates `θ_t = θ_{t-1} - η ∇_θ L_local` can be approximated using STDP-like rules where synaptic weights are modified based on relative spike timing between pre- and post-synaptic neurons. The sliding window for local adaptation naturally aligns with the temporal dynamics of spiking neurons. The selective adaptation (only updating subset of parameters) maps to neuromodulation in biological systems where specific synapses are selectively modified. The resulting Spiking-MesaNet combines the adaptability of test-time training with the energy efficiency of sparse, event-driven computation. The local learning rules, when implemented through STDP and other spike-based plasticity mechanisms, provide a biologically plausible way to achieve online adaptation. This makes Spiking-MesaNet particularly suitable for neuromorphic implementations of adaptive sequence models where the system must continuously adjust to changing input distributions, with the local test-time training enabling rapid adaptation to new contexts while maintaining the energy efficiency of neuromorphic hardware through spike-based local learning rules that don't require backpropagation.
