**Problem Addressed:** Continuous-time state space models (SSMs) offer a principled approach to sequence modeling with strong theoretical properties for capturing long-range dependencies (LRDs), but prior implementations suffered from prohibitive computational and memory requirements. The core challenge was that computing the SSM's convolution kernel required O(N²) operations for sequence length N, making it infeasible for long sequences. Additionally, the state matrices in SSMs were difficult to parameterize stably—naive approaches led to numerical instability or vanishing/exploding gradients. The fundamental question was: how to make SSMs computationally tractable while preserving their theoretical advantages for modeling LRDs?

**Key Innovation** - Structured Parameterization with Cauchy Kernel: S4 introduces a novel parameterization that decomposes the state matrix A as A = Λ - PQ* (diagonal plus low-rank), where Λ is diagonal and P, Q are low-rank matrices. This structured decomposition enables two critical optimizations: (1) The diagonal component can be stably diagonalized, and (2) The low-rank correction can be handled via the Woodbury identity. The core token mixer computes the SSM convolution kernel K through: First, the state space model is defined as h'(t) = Ah(t) + Bx(t), y(t) = Ch(t). After discretization with step size Δ, this becomes a discrete recurrence. The key insight is that computing K reduces to evaluating a Cauchy kernel: K̂(ω) = (C̃ - (2/(1+ω))Λ)^(-1)[B P], which can be computed efficiently using FFT. This transforms the O(N²) computation into O(N log N).

**Implementation Details:**
- Structured state matrix: A = Λ - PQ* where Λ ∈ C^N is diagonal, P, Q ∈ C^N are low-rank
- HiPPO initialization: Uses optimal polynomial projection theory to initialize Λ, P, Q for capturing history
- Cauchy kernel computation: Reduces SSM to evaluating (ω - λ_i)^(-1) at roots of unity
- FFT-based convolution: Computes K̂ at frequency domain, then inverse FFT for time domain kernel
- Discretization: Uses bilinear transform to convert continuous-time to discrete-time
- Parallel training: Convolution form enables parallel computation across sequence
- O(N log N) complexity for sequence length N, O(N) memory

**SNN Compatibility & Expected Impact:** S4's structured state space formulation with diagonal-plus-low-rank decomposition is highly compatible with SNN conversion. The diagonal state matrix Λ can be implemented using populations of spiking neurons with heterogeneous time constants, where each diagonal element corresponds to a neuron with specific leak rate. Converting all linear projections (B, C, P, Q matrices) to SpikingLinear layers introduces event-driven sparsity. The low-rank correction PQ* can be efficiently realized in neuromorphic hardware through structured connectivity between two small populations of neurons. The HiPPO initialization, which optimally projects history onto polynomial basis, naturally aligns with temporal coding in spiking neurons where different neurons encode different timescales. The discretization step maps directly to the discrete-time dynamics of spiking neurons. The resulting Spiking-S4 combines the principled approach to long-range dependencies with the energy efficiency of sparse, event-driven computation. The structured parameterization, when implemented through heterogeneous spiking neural populations with carefully designed connectivity, enables efficient capture of multi-timescale dynamics. This makes Spiking-S4 particularly suitable as a foundation for neuromorphic implementations of the entire Mamba family, providing the theoretical framework and computational efficiency needed for long-sequence modeling on neuromorphic hardware while maintaining the strong inductive biases for temporal processing that make SSMs effective.
