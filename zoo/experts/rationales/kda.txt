**Problem Addressed:** Gated DeltaNet improved upon DeltaNet by integrating with Mamba2's SSD framework, but it still used scalar gating (single decay value per timestep) which limits fine-grained control over memory. For complex tasks requiring nuanced memory management, scalar gating cannot selectively retain or forget different features independently. Additionally, existing implementations of gated delta rule suffer from numerical precision issues when using fine-grained decay, requiring computations in logarithmic domain which prevents full utilization of half-precision matrix multiplications. The challenge is to design a delta attention mechanism with fine-grained, per-dimension control while maintaining hardware efficiency.

**Key Innovation - Fine-Grained Diagonal Gating:** KDA introduces diagonal gating Diag(α_t) instead of scalar gating, enabling per-dimension control over memory decay. The core token mixer implements: S_t = Diag(α_t) S_{t-1} + k_t v_t^T where α_t ∈ R^d is a vector of decay values, one per dimension. This allows different features to have different retention rates. The key algorithmic innovation is binding both the decay vector and the key vector to the same computation (a_t = b_t = k_t in DPLR formulation), which alleviates numerical precision issues. This enables efficient computation in half-precision without requiring logarithmic domain operations or secondary chunking. The fine-grained gating provides: (1) Better positional awareness—different dimensions can encode position differently, (2) Enhanced memory management—selective retention per feature, (3) Hardware efficiency—full utilization of tensor cores with half-precision.

**Implementation Details:**
- Diagonal gating: α_t = σ(x_t W_α) ∈ R^d provides per-dimension decay control
- Efficient DPLR formulation: Binds decay and key vectors to avoid precision issues
- Half-precision computation: Enables full use of GPU tensor cores without logarithmic domain
- Chunk-wise parallel training: Processes sequences in chunks for hardware efficiency
- Reduced secondary chunking: Only 2 matrix computations instead of 4 (compared to GLA)
- Hybrid architecture: 3:1 KDA-to-global-attention ratio in Kimi Linear model
- State size: Compact recurrent state for O(1) inference
- 6× faster decoding than full attention at long sequences (1M tokens)

**SNN Compatibility & Expected Impact:** KDA's fine-grained diagonal gating maps naturally to heterogeneous populations of spiking neurons with diverse dynamics. The per-dimension decay α_t ∈ R^d can be implemented using separate populations of spiking neurons, each with different membrane time constants and refractory periods. Converting all linear projections (W_α, k_proj, v_proj, output projections) to SpikingLinear layers introduces event-driven sparsity. The diagonal gating Diag(α_t) can be realized through population-specific gain modulation, where each neural population has its own adaptive leak rate. The binding of decay and key vectors (a_t = b_t = k_t) simplifies the neuromorphic implementation by reducing the number of separate computations needed. The fine-grained control enables different neural populations to specialize in different temporal scales and feature types. The resulting Spiking-KDA combines the expressiveness of per-dimension memory control with the energy efficiency of sparse, event-driven computation. The diagonal gating, when implemented through heterogeneous spiking neural populations, provides a biologically plausible mechanism for selective memory management where different features can be retained or forgotten independently based on their relevance. This makes Spiking-KDA particularly suitable for neuromorphic implementations of large language models requiring both fine-grained memory control and hardware efficiency, with the per-dimension gating enabling the model to adaptively manage different aspects of information based on context while maintaining the computational efficiency needed for deployment on neuromorphic chips. The hybrid architecture in Kimi Linear (3:1 KDA-to-attention ratio) can be efficiently mapped to neuromorphic systems with separate processing pathways for local (KDA) and global (attention) information integration.
