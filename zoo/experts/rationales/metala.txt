**Problem Addressed:** Linear attention models aim to approximate softmax attention with linear complexity, but existing approaches suffer from suboptimal approximation quality and parameter redundancy. Models like GLA use low-rank parameterization for gating which sacrifices expressiveness, and most linear attention variants still use Key matrices which may be redundant. The fundamental question is: what are the necessary and sufficient conditions for optimal linear approximation to softmax attention, and how can we design a linear attention mechanism that satisfies these conditions while eliminating unnecessary parameters?

**Key Innovation - Optimal Linear Approximation without Key Matrices:** MetaLA provides a unified theoretical framework identifying necessary conditions for optimal linear approximation to softmax attention, then proposes a module satisfying these conditions. The core innovation is eliminating Key matrices entirely—instead of S_t = S_{t-1} + k_t^T v_t, MetaLA uses: S_t = Diag(α_t) S_{t-1} + v_t (1-α_t)^T. The token mixer computes: o_t = q_t S_t where the state is updated without explicit keys. The decay α_t = σ(x_t W_α) is computed using full-rank matrix W_α (not low-rank like GLA), enabling richer dynamics. MetaLA adds two enhancements: (1) Self-augmentation: o_t = q_t S_t + σ_aug(q_t) ⊙ (w_aug ⊙ (1-α_t))^T v_t, which enhances token's attention to itself, avoiding attention dilution. (2) Short convolutions for local interactions.

**Implementation Details:**
- No Key matrices: Eliminates W_K, reducing parameters and computation
- Full-rank decay: W_α ∈ R^{d×d} instead of low-rank, enabling richer expressiveness
- State update: S_t = Diag(α_t) S_{t-1} + v_t (1-α_t)^T uses value-based updates
- Self-augmentation: Explicit term for self-attention to avoid dilution
- Short convolutions: Enhances local interactions (kernel size 3-4)
- Dynamic decay: α_t = σ(x_t W_α) adapts based on input content
- Optimal approximation: Satisfies necessary conditions for approximating softmax attention
- Better performance than GLA, Mamba, and comparable to Transformers on language modeling

**SNN Compatibility & Expected Impact:** MetaLA's key-free architecture with self-augmentation is highly compatible with SNN conversion. The elimination of Key matrices simplifies the neuromorphic implementation by reducing the number of projection layers needed. Converting the remaining linear projections (q_proj, v_proj, W_α, w_aug, output projections) to SpikingLinear layers introduces event-driven sparsity. The full-rank decay matrix W_α can be implemented using fully-connected populations of spiking neurons, enabling rich adaptive dynamics. The state update S_t = Diag(α_t) S_{t-1} + v_t (1-α_t)^T can be realized through diagonal gain modulation combined with outer-product connectivity patterns. The self-augmentation mechanism, which enhances self-attention, can be implemented using recurrent self-connections in spiking neurons—a common feature in biological neural systems. The short convolutions map to local connectivity patterns with specific temporal delays. The resulting Spiking-MetaLA combines the parameter efficiency of key-free architecture with the energy efficiency of sparse, event-driven computation. The self-augmentation, when implemented through recurrent self-connections in spiking networks, provides a biologically plausible mechanism for maintaining token identity while integrating contextual information. This makes Spiking-MetaLA particularly suitable for neuromorphic implementations where both parameter efficiency and computational efficiency are critical, with the key-free design reducing synaptic connectivity requirements while the full-rank decay enables rich adaptive dynamics. The optimal approximation framework provides theoretical guarantees for the quality of linear attention, making MetaLA an attractive choice for neuromorphic language models requiring strong performance with minimal hardware resources.
