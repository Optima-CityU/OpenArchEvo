**Problem Addressed:** Transformers and linear attention models lack a unified theoretical framework for understanding their memory mechanisms and update rules. While the delta rule has been applied to linear attention (DeltaNet), its relationship to softmax attention and the fundamental principles governing memory in Transformers remain unclear. The challenge is to develop a comprehensive theory that explains how different Transformer variants store and retrieve information, and to use this understanding to design improved architectures that combine the benefits of both softmax attention and delta rule updates.

**Key Innovation - Unified Associative Memory Framework with Hybrid Delta-Softmax:** DeltaFormer provides a theoretical framework viewing Transformers through the lens of associative memory, analyzing both memory capacity (how much can be stored) and memory update (how memories evolve). The core insight is that both softmax attention and linear attention with delta rule can be understood as different memory update mechanisms. DeltaFormer proposes a hybrid approach combining delta rule updates with softmax normalization. The token mixer implements: For the delta rule component: S_t = S_{t-1}(I - β_t k_t k_t^T) + β_t v_t k_t^T (selective forgetting and writing). For the softmax component: attention scores are computed with softmax normalization. The hybrid combines both: using delta rule for associative memory updates while leveraging softmax for better retrieval through its kernel properties. The framework introduces retrieval SNR (signal-to-noise ratio) to measure memory capacity and shows why softmax attention is effective through kernel perspective.

**Implementation Details:**
- Hybrid architecture: Combines delta rule updates with softmax attention mechanisms
- Retrieval SNR metric: Measures memory capacity and retrieval quality
- Kernel perspective: Analyzes attention through kernel functions for theoretical understanding
- Memory capacity analysis: Quantifies how much information can be stored and retrieved
- Memory update framework: Unifies different Transformer variants (DeltaNet, softmax attention)
- Can use nonlinear kernels: Extends beyond linear kernels for enhanced expressivity
- Theoretical foundation: Provides mathematical framework for understanding Transformer behavior
- Surpasses TC^0 complexity: Achieves expressivity beyond standard Transformer limitations

**SNN Compatibility & Expected Impact:** DeltaFormer's hybrid delta-softmax architecture with associative memory framework is highly compatible with SNN conversion. The delta rule component, which performs selective forgetting and writing, maps naturally to spike-timing-dependent plasticity (STDP) mechanisms in biological neurons. Converting all linear projections (k_proj, v_proj, q_proj, β_proj, output projections) to SpikingLinear layers introduces event-driven sparsity. The Householder-like updates in the delta rule can be implemented through structured inhibitory connectivity in spiking networks. The softmax component can be approximated using lateral inhibition mechanisms common in biological neural systems, where competing neurons suppress each other. The hybrid approach enables the model to leverage both the associative memory properties of delta rule (implemented through STDP-like mechanisms) and the retrieval capabilities of softmax (implemented through lateral inhibition). The retrieval SNR framework provides a principled way to analyze memory capacity in spiking implementations. The resulting Spiking-DeltaFormer combines the theoretical elegance of associative memory with the energy efficiency of sparse, event-driven computation. The hybrid architecture, when implemented through combinations of STDP and lateral inhibition in spiking networks, provides a biologically plausible mechanism for both memory storage and retrieval. This makes Spiking-DeltaFormer particularly suitable for neuromorphic implementations where understanding and optimizing memory mechanisms is crucial, with the unified framework enabling systematic design of spiking architectures that balance memory capacity, retrieval quality, and energy efficiency on neuromorphic hardware.
