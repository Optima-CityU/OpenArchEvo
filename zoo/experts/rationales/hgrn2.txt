**Problem Addressed:** HGRN demonstrated competitive performance with data-dependent gating, but its vector-valued states (one scalar per channel) limited expressiveness compared to models with matrix-valued states like Mamba, GLA, and RWKV-6. The small recurrent state size restricted memory capacity, preventing HGRN from achieving LLaMA-level language modeling performance. The challenge was to expand HGRN's state size to enhance memory capacity while maintaining training efficiency and the benefits of data-dependent gating.

**Key Innovation - Outer-Product State Expansion:** HGRN2 introduces a simple outer-product-based state expansion mechanism that significantly enlarges the recurrent state without adding parameters. The core token mixer implements: `S_t = α_t ⊙ S_{t-1} + k_t v_t^T` where now S_t ∈ R^{d_k × d_v} is a matrix (not vector). The forget gate `α_t = γ + (1-γ)σ(x_t W_α)` uses a learnable baseline γ plus data-dependent modulation. The key insight is that by using outer products `k_t v_t^T`, the state expands from d dimensions (HGRN) to d_k × d_v dimensions (HGRN2), dramatically increasing memory capacity. This can be reformulated as linear attention: `o_t = q_t S_t = q_t (Σ_{i≤t} α_t...α_{i+1} k_i v_i^T)`, enabling hardware-efficient training using GLA's chunk-wise parallel algorithm.

**Implementation Details:**
- Matrix-valued states: S_t ∈ R^{d_k × d_v} via outer products k_t v_t^T
- State expansion ratio: typically d_k = d_v = d/h per head, expanding from d to d²/h² per head
- Forget gate with baseline: `α_t = γ + (1-γ)σ(x_t W_α)` where γ is learned
- Equivalent to linear attention formulation: enables use of GLA's efficient training algorithm
- Chunk-wise parallel training: processes sequences in chunks for hardware efficiency
- Multi-headed architecture: each head maintains separate matrix-valued state
- Significantly improved memory capacity over HGRN while maintaining O(1) inference

**SNN Compatibility & Expected Impact:** HGRN2's matrix-valued states with outer-product expansion are highly compatible with SNN conversion. The outer product `k_t v_t^T` can be implemented using populations of spiking neurons with all-to-all connectivity, where spike coincidences between key and value neurons create associative bindings. Converting all linear projections (q_proj, k_proj, v_proj, W_α, output projections) to SpikingLinear layers introduces event-driven sparsity. The forget gate with learnable baseline `α_t = γ + (1-γ)σ(x_t W_α)` can be realized using spiking neurons with both tonic (baseline γ) and phasic (data-dependent) components, similar to neuromodulatory systems in biological brains. The matrix-valued state can be maintained in neuromorphic hardware using 2D arrays of neurons with structured connectivity. The element-wise gating `α_t ⊙ S_{t-1}` can be implemented through gain modulation across the entire state matrix. The resulting Spiking-HGRN2 combines the enhanced memory capacity of matrix-valued states with the energy efficiency of sparse, event-driven computation. The outer-product mechanism, when implemented through spike-based coincidence detection, enables rich associative memory formation. This makes Spiking-HGRN2 particularly suitable for neuromorphic implementations of language models where both large memory capacity and energy efficiency are critical, with the data-dependent gating enabling adaptive information retention and the expanded state providing sufficient capacity for complex language modeling tasks.
