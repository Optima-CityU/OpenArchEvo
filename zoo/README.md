# Architecture zoo

Source code of the spiking sequence blocks trained in the paper's search, plus
a separate set of ASI-Arch-derived programs from an earlier study. Files are
shipped as recovered, without reformatting; `index.csv` lists every program
with its metrics and SHA-256. No weights are included.

| Folder | Files | What it is |
|---|---|---|
| `experts/` | 20 | Initial archive (iteration 0): spiking versions of 20 published linear-attention / SSM families; design rationales in `experts/rationales/` |
| `discovered/iter_01/ … iter_10/` | 151 | Programs generated by the search and trained on both proxy tasks, by outer iteration; LLM rationales in `discovered/rationales/` |
| `elites/` | 3 | The three architectures analysed in the paper, with readable names and comments |
| `asi_arch/` | 118 | ASI-Arch token-mixer programs (106) and baselines (12) from an earlier study |
| `asi_arch/fullspike/` | 34 | Fully spiking LLM rewrites of ASI-Arch programs from the same study |

`elites/` holds commented copies of three discovered programs (same code,
same Python AST without docstrings):

| Name | Key | Archive file |
|---|---|---|
| NeuroGate | `i09-s0557` | `discovered/iter_09/i09-s0557_neurogate.py` |
| HomeoResSSM | `i03-s0335` | `discovered/iter_03/i03-s0335_homeoresssm.py` |
| LoopMem | `i07-s0884` | `discovered/iter_07/i07-s0884_loopmem.py` |

NeuroGate's token mixer defaults to `use_gate=False`; pass `use_gate=True` for
the output-gate setting used in the paper.

## Loading a block

Every expert, discovered and `elites/` file defines `SpikingFLABlock`: a
pre-norm residual block with a spiking token mixer and a spiking MLP, mapping
`(B, L, d_model)` to `(B, L, d_model)`.

```python
import torch
from openarchevo.models import load_block_class   # maps the files' legacy imports onto openarchevo.models

Block = load_block_class("zoo/elites/NeuroGate.py")
block = Block(d_model=128, num_heads=4, d_ffn_mult=2, dropout=0.1, neuron_type="bptt")
hidden, reg_loss, spikes = block(torch.randn(2, 512, 128))
fire_rate = spikes.float().mean() if spikes is not None else None
```

* `forward` returns `(hidden, reg_loss, spikes)`; `spikes` is every binary
  spike tensor in the block, flattened and concatenated.
* Most files need `flash-linear-attention` and `einops`
  (`pip install -e ".[zoo]"`), and therefore a CUDA GPU. The three blocks in
  `examples/blocks/` run on CPU.
* `training/train_*.py --program <file>` trains any of these files with the
  search's proxy settings (`configs/training/`).
* The ASI-Arch token-mixer programs are layers, not complete blocks; the
  wrapper used in the earlier study is not included.

## index.csv

| Column | Meaning |
|---|---|
| `key`, `collection`, `iteration`, `sample`, `name` | Identity (`iteration` empty for ASI rows) |
| `base_family` | Token-mixer family the program builds on |
| `wt2_ppl_reported` | Reported WikiText-2 perplexity |
| `listops_acc` | ListOps proxy accuracy, % (trained on 1/3 of the training data; not a full LRA result) |
| `fitness_paper` | Fitness from `openarchevo/fitness.py` (anchor: SpikingDeltaNet, WT2 58.28, ListOps 53.0) |
| `fire_rate_wt2`, `fire_rate_listops` | Firing rate at the last logged training epoch (often missing for ListOps) |
| `file`, `sha256` | Path within `zoo/` and SHA-256 of the file |
| `subset` | `initial_expert`, `search_candidate`, `paper_analysed`, `asi_arch_discovered`, `baseline` or `fullspike_rewrite` |
| `has_csv_results`, `notes` | ASI result source; row-specific remarks |

Naming: discovered files are `iNN-sSSSS_<slug>.py` (outer iteration, archive
sample number); experts are `i00-<family>`; ASI rows are `asi-<id>`. ASI rows
come from a different protocol, so do not rank them against the main search.

Provenance and per-file notes (metric splits, log coverage, testing status):
[docs/zoo-provenance.md](../docs/zoo-provenance.md).
